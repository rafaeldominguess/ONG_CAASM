# Clube Amigos dos Animais - Santa Maria

Website institucional desenvolvido para o **Clube Amigos dos Animais de Santa Maria - RS**, uma organização não governamental dedicada à proteção animal, à adoção responsável e à conscientização da comunidade.

Este projeto foi desenvolvido como atividade acadêmica para a faculdade **Cruzeiro do Sul**, com o objetivo de criar uma página moderna, acessível e informativa para apresentar o propósito da ONG e facilitar o contato com pessoas interessadas em apoiar a causa.

## Demonstração

Acesse o projeto publicado:

[Clube Amigos dos Animais - Website](https://clubeamigosdosanimaissm-pi.vercel.app/)

## Sobre o projeto

O site apresenta informações sobre a ONG, seus objetivos e as principais formas de contribuição da comunidade.

A organização atua desde 1993 na defesa dos direitos dos animais e no incentivo ao respeito à natureza e a todas as formas de vida.

## Funcionalidades

- Página inicial com apresentação da ONG;
- Seção “Quem somos?”;
- Apresentação dos principais objetivos da organização;
- Galeria de imagens;
- Informações sobre formas de apoio;
- Orientações para doações financeiras e materiais;
- Possibilidade de oferecer lar temporário;
- Links para Instagram e Facebook;
- Botões de contato via WhatsApp;
- Menu de navegação responsivo;
- Layout adaptado para computadores, tablets e celulares;
- Navegação suave entre as seções da página.

## Tecnologias utilizadas

## Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

### 2. Acesse a pasta do projeto

```bash
cd Projeto_Ong
```

### 3. Execute o projeto

Como este é um projeto desenvolvido com HTML, CSS e JavaScript puro, não é necessário instalar dependências.

Você pode abrir o arquivo `index.html` diretamente no navegador ou utilizar uma extensão como o **Live Server** no Visual Studio Code.

### Utilizando o Live Server

1. Abra a pasta do projeto no Visual Studio Code;
2. Instale a extensão **Live Server**;
3. Clique com o botão direito sobre o arquivo `index.html`;
4. Selecione **Open with Live Server**;
5. O site será aberto automaticamente no navegador.

## Organização das seções

### Início

Apresenta o nome da ONG, sua principal mensagem e um botão para contato direto pelo WhatsApp.

### Quem somos

Explica a história e o propósito do Clube Amigos dos Animais de Santa Maria - RS.

### Objetivos

Apresenta as principais áreas de atuação da ONG:

- Resgate e proteção animal;
- Adoção responsável;
- Controle populacional;
- Educação comunitária.

### Galeria

Exibe imagens relacionadas ao trabalho desenvolvido pela organização.

### Como apoiar

Mostra diferentes formas de ajudar a causa:

- Doação financeira;
- Doação de ração e medicamentos;
- Disponibilização de lar temporário;
- Divulgação da causa e dos animais disponíveis para adoção.

### Dúvidas e contato

Disponibiliza um canal de comunicação via WhatsApp para que os visitantes possam tirar dúvidas e obter mais informações.

## Responsividade

O projeto foi desenvolvido para funcionar em diferentes tamanhos de tela:

- Computadores;
- Notebooks;
- Tablets;
- Smartphones.

Em telas menores, o menu principal é substituído por um menu hambúrguer para melhorar a experiência de navegação.

## Objetivo acadêmico

Este projeto foi desenvolvido como parte de uma atividade acadêmica da faculdade **Cruzeiro do Sul**.

A proposta consistia em desenvolver um website para uma ONG, apresentando sua identidade, seu propósito, seus projetos e formas de participação da comunidade.

Além da aplicação dos conhecimentos técnicos de desenvolvimento web, o projeto buscou criar uma solução digital com impacto social, ajudando a organização a divulgar seu trabalho e alcançar mais pessoas interessadas na proteção animal.
